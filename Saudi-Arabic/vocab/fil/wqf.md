# وقف

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | وقف |
| **Present** | يوقف |
| **Meaning** | stopping / standing |
| **Root** | [و-ق-ف](#roots/wqf) |
| **Form** | I · وقف / يوقف · base meaning: stopping / standing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">وقف هنا</span> | <span class="example-en" dir="ltr" lang="en">Stop here</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | وقفت | أأقف | بأقف |
| إحنا | وقفنا | نأقف | بنأقف |
| أنت | وقفت | تأقف | بتأقف |
| أنتِ | وقفتي | تأقفين | بتأقفين |
| أنتم | وقفتوا | تأقفون | بتأقفون |
| هو | وقف | يأقف | بيأقف |
| هي | وقفت | تأقف | بتأقف |
| هم | وقفوا | يأقفون | بيأقفون |
