# ذ-ك-ر

| Field | Value |
|-------|-------|
| **Root** | ذ-ك-ر |
| **Letter** | ذ · ذال |
| **Meaning** | mentioning / remembering |
| **Form I** | ذكر / يذكر |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

---

## Example

| Arabic · English |
|------------------|
| تذكرت اسمه — I remembered his name |
