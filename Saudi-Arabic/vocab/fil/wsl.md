# وصل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | وصل |
| **Present** | يوصل |
| **Meaning** | arriving / connecting |
| **Root** | [و-ص-ل](#roots/wsl) |
| **Form** | I · وصل / يوصل · base meaning: arriving / connecting |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">وصلت البيت</span> | <span class="example-en" dir="ltr" lang="en">I arrived home</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | وصلت | أوصل | بوصل |
| إحنا | وصلنا | نوصل | بنوصل |
| أنت | وصلت | توصل | بتوصل |
| أنتِ | وصلتي | توصلين | بتوصلين |
| أنتم | وصلتوا | توصلون | بتوصلون |
| هو | وصل | يوصل | بيوصل |
| هي | وصلت | توصل | بتوصل |
| هم | وصلوا | يوصلون | بيوصلون |
