# أمر

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | أمر |
| **Present** | يأمر |
| **Meaning** | ordering / commanding |
| **Root** | [أ-م-ر](#roots/amr) |
| **Form** | I · أمر / يأمر · base meaning: ordering / commanding |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أمرني أسويها</span> | <span class="example-en" dir="ltr" lang="en">He told me to do it</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | أمرت | أأمر | بأمر |
| إحنا | أمرنا | نأمر | بنأمر |
| أنت | أمرت | تأمر | بتأمر |
| أنتِ | أمرتي | تأمرين | بتأمرين |
| أنتم | أمرتوا | تأمرون | بتأمرون |
| هو | أمر | يأمر | بيأمر |
| هي | أمرت | تأمر | بتأمر |
| هم | أمروا | يأمرون | بيأمرون |
