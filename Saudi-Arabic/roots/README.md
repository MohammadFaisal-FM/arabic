# Roots Library

Searchable A–Z index in the app (**Roots** tab). Grouped by first letter of the root.

**Live:** https://mohammadfaisal-fm.github.io/arabic/#roots

High-frequency everyday Arabic roots for learners (Saudi/Najdi focus). Not a complete dictionary — classical Arabic has thousands of roots.
