# نظر

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | نظر |
| **Present** | ينظر |
| **Meaning** | looking |
| **Root** | [ن-ظ-ر](#roots/nzr) |
| **Form** | I · نظر / ينظر · base meaning: looking |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | نظرت | أنظر | بنظر |
| إحنا | نظرنا | ننظر | بننظر |
| أنت | نظرت | تنظر | بتنظر |
| أنتِ | نظرتي | تنظرين | بتنظرين |
| أنتم | نظرتوا | تنظرون | بتنظرون |
| هو | نظر | ينظر | بينظر |
| هي | نظرت | تنظر | بتنظر |
| هم | نظروا | ينظرون | بينظرون |
