# نزل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | نزل |
| **Present** | ينزل |
| **Meaning** | going down / getting off |
| **Root** | [ن-ز-ل](#roots/nzl) |
| **Form** | I · نزل / ينزل · base meaning: going down / getting off |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">نزلت من السيارة</span> | <span class="example-en" dir="ltr" lang="en">I got out of the car</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | نزلت | أنزل | بنزل |
| إحنا | نزلنا | ننزل | بننزل |
| أنت | نزلت | تنزل | بتنزل |
| أنتِ | نزلتي | تنزلين | بتنزلين |
| أنتم | نزلتوا | تنزلون | بتنزلون |
| هو | نزل | ينزل | بينزل |
| هي | نزلت | تنزل | بتنزل |
| هم | نزلوا | ينزلون | بينزلون |
