# حفظ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | حفظ |
| **Present** | يحفظ |
| **Meaning** | memorizing / keeping |
| **Root** | [ح-ف-ظ](#roots/hfz) |
| **Form** | I · حفظ / يحفظ · base meaning: memorizing / keeping |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">حفظت الدرس</span> | <span class="example-en" dir="ltr" lang="en">I memorized the lesson</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | حفظت | أحفظ | بحفظ |
| إحنا | حفظنا | نحفظ | بنحفظ |
| أنت | حفظت | تحفظ | بتحفظ |
| أنتِ | حفظتي | تحفظين | بتحفظين |
| أنتم | حفظتوا | تحفظون | بتحفظون |
| هو | حفظ | يحفظ | بيحفظ |
| هي | حفظت | تحفظ | بتحفظ |
| هم | حفظوا | يحفظون | بيحفظون |
