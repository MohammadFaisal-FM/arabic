# جرّب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | جرّب |
| **Present** | يجرّب |
| **Meaning** | trying |
| **Root** | [ج-ر-ب](#roots/jrb) |
| **Form** | II · جرّب / يجرّب · derived from Form I (جرب / يجرب) |

| Arabic | English |
|--------|---------|

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | جرّبت | أجرّب | بجرّب |
| إحنا | جرّبنا | نجرّب | بنجرّب |
| أنت | جرّبت | تجرّب | بتجرّب |
| أنتِ | جرّبتي | تجرّبين | بتجرّبين |
| أنتم | جرّبتوا | تجرّبون | بتجرّبون |
| هو | جرّب | يجرّب | بيجرّب |
| هي | جرّبت | تجرّب | بتجرّب |
| هم | جرّبوا | يجرّبون | بيجرّبون |
