# خاف

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | خاف |
| **Present** | يخاف |
| **Meaning** | fearing |
| **Root** | [خ-و-ف](#roots/khaf) |
| **Form** | I · خاف / يخاف |

## Example

| Arabic · English |
|------------------|
| ما أخاف — I’m not afraid |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | خافت | أخاف | بخاف |
| إحنا | خافنا | نخاف | بنخاف |
| أنت | خافت | تخاف | بتخاف |
| أنتِ | خافتي | تخافين | بتخافين |
| أنتم | خافتوا | تخافون | بتخافون |
| هو | خاف | يخاف | بيخاف |
| هي | خافت | تخاف | بتخاف |
| هم | خافوا | يخافون | بيخافون |
