# دار

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | دار |
| **Present** | يدور |
| **Meaning** | turning / looking for |
| **Root** | [د-و-ر](#roots/dwr) |
| **Form** | I · دار / يدور · base meaning: turning / looking for |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أدور على مفتاح</span> | <span class="example-en" dir="ltr" lang="en">I’m looking for a key</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | دارت | أدور | بدور |
| إحنا | دارنا | ندور | بندور |
| أنت | دارت | تدور | بتدور |
| أنتِ | دارتي | تدورين | بتدورين |
| أنتم | دارتوا | تدورون | بتدورون |
| هو | دار | يدور | بيدور |
| هي | دارت | تدور | بتدور |
| هم | داروا | يدورون | بيدورون |
