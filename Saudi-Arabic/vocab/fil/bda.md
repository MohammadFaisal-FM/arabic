# بدأ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | بدأ |
| **Present** | يبدأ |
| **Meaning** | starting |
| **Root** | [ب-د-أ](#roots/bda) |
| **Form** | I · بدأ / يبدأ · base meaning: starting |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">بدأت الدرس</span> | <span class="example-en" dir="ltr" lang="en">I started the lesson</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | بدأت | أبدأ | ببدأ |
| إحنا | بدأنا | نبدأ | بنبدأ |
| أنت | بدأت | تبدأ | بتبدأ |
| أنتِ | بدأتي | تبدأين | بتبدأين |
| أنتم | بدأتوا | تبدأون | بتبدأون |
| هو | بدأ | يبدأ | بيبدأ |
| هي | بدأت | تبدأ | بتبدأ |
| هم | بدأوا | يبدأون | بيبدأون |
