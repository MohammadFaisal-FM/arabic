| Field | Value |
|-------|-------|
| **Root** | ق-و-ل |
| **Letter** | ق · قاف |
| **Meaning** | saying |
| **Form I** | قال / يقول |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |
