# وجد

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | وجد |
| **Present** | يوجد |
| **Meaning** | finding / existing |
| **Root** | [و-ج-د](#roots/wjd) |

| Arabic · English |
|------------------|

## Conjugation

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | وجدت | أوجد | بوجد |
| إحنا | وجدنا | نوجد | بنوجد |
| أنت | وجدت | توجد | بتوجد |
| أنتِ | وجدتي | توجدين | بتوجدين |
| أنتم | وجدتوا | توجدون | بتوجدون |
| هو | وجد | يوجد | بيوجد |
| هي | وجدت | توجد | بتوجد |
| هم | وجدوا | يوجدون | بيوجدون |
