# فقد

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | فقد |
| **Present** | يفقد |
| **Meaning** | losing |
| **Root** | [ف-ق-د](#roots/fqd) |
| **Form** | I · فقد / يفقد · base meaning: losing |

| Arabic | English |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | فقدت | أفقد | بفقد |
| إحنا | فقدنا | نفقد | بنفقد |
| أنت | فقدت | تفقد | بتفقد |
| أنتِ | فقدتي | تفقدين | بتفقدين |
| أنتم | فقدتوا | تفقدون | بتفقدون |
| هو | فقد | يفقد | بيفقد |
| هي | فقدت | تفقد | بتفقد |
| هم | فقدوا | يفقدون | بيفقدون |
