# خرج

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | خرج |
| **Present** | يخرج |
| **Meaning** | going out |
| **Root** | [خ-ر-ج](#roots/khrj) |
| **Form** | I · خرج / يخرج · base meaning: going out |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">خرجت من البيت</span> | <span class="example-en" dir="ltr" lang="en">I left the house</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | خرجت | أخرج | بخرج |
| إحنا | خرجنا | نخرج | بنخرج |
| أنت | خرجت | تخرج | بتخرج |
| أنتِ | خرجتي | تخرجين | بتخرجين |
| أنتم | خرجتوا | تخرجون | بتخرجون |
| هو | خرج | يخرج | بيخرج |
| هي | خرجت | تخرج | بتخرج |
| هم | خرجوا | يخرجون | بيخرجون |
