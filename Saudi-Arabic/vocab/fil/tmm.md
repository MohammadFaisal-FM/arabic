# تمّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | تمّ |
| **Present** | يتم |
| **Meaning** | completing |
| **Root** | [ت-م-م](#roots/tmm) |
| **Form** | I · تمّ / يتم |

## Example

| Arabic · English |
|------------------|
| تمّ الشغل — The work is done |

---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | تمّت | أتم | بتم |
| إحنا | تمّنا | نتم | بنتم |
| أنت | تمّت | تتم | بتتم |
| أنتِ | تمّتي | تتمين | بتتمين |
| أنتم | تمّتوا | تتمون | بتتمون |
| هو | تمّ | يتم | بيتم |
| هي | تمّت | تتم | بتتم |
| هم | تمّوا | يتمون | بيتمون |
