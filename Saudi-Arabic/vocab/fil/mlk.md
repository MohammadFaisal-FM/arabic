# ملك

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ملك |
| **Present** | يملك |
| **Meaning** | owning |
| **Root** | [م-ل-ك](#roots/mlk) |
| **Form** | I · ملك / يملك · base meaning: owning |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ملكت | أملك | بملك |
| إحنا | ملكنا | نملك | بنملك |
| أنت | ملكت | تملك | بتملك |
| أنتِ | ملكتي | تملكين | بتملكين |
| أنتم | ملكتوا | تملكون | بتملكون |
| هو | ملك | يملك | بيملك |
| هي | ملكت | تملك | بتملك |
| هم | ملكوا | يملكون | بيملكون |
