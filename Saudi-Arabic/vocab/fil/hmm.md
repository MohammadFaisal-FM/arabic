# همّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | همّ |
| **Present** | يهم |
| **Meaning** | being concerned |
| **Root** | [ه-م-م](#roots/hmm) |
| **Form** | I · همّ / يهم · base meaning: being concerned |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">يهمني الأمر</span> | <span class="example-en" dir="ltr" lang="en">This matters to me</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | همّت | أهم | بهم |
| إحنا | همّنا | نهم | بنهم |
| أنت | همّت | تهم | بتهم |
| أنتِ | همّتي | تهمين | بتهمين |
| أنتم | همّتوا | تهمون | بتهمون |
| هو | همّ | يهم | بيهم |
| هي | همّت | تهم | بتهم |
| هم | همّوا | يهمون | بيهمون |
