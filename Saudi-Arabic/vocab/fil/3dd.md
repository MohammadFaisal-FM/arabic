# عدّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | عدّ |
| **Present** | يعد |
| **Meaning** | counting |
| **Root** | [ع-د-د](#roots/3dd) |
| **Form** | I · عدّ / يعد |

---

## Example

| Arabic · English |
|------------------|
| عدّ الفلوس — Count the money |

---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | عدّت | أعد | بعد |
| إحنا | عدّنا | نعد | بنعد |
| أنت | عدّت | تعد | بتعد |
| أنتِ | عدّتي | تعدين | بتعدين |
| أنتم | عدّتوا | تعدون | بتعدون |
| هو | عدّ | يعد | بيعد |
| هي | عدّت | تعد | بتعد |
| هم | عدّوا | يعدون | بيعدون |
