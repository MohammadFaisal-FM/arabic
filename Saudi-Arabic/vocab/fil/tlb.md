# طلب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | طلب |
| **Present** | يطلب |
| **Meaning** | requesting / ordering |
| **Root** | [ط-ل-ب](#roots/tlb) |
| **Form** | I · طلب / يطلب |

---

## Example

| Arabic · English |
|------------------|
| طلبت قهوة — I ordered coffee |

| إحنا | طلبنا | نطلب | بنطلب |
| أنت | طلبت | تطلب | بتطلب |
| أنتِ | طلبتي | تطلبين | بتطلبين |
| أنتم | طلبتوا | تطلبون | بتطلبون |
| هو | طلب | يطلب | بيطلب |
| هي | طلبت | تطلب | بتطلب |
| هم | طلبوا | يطلبون | بيطلبون |
