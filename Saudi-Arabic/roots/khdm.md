| Field | Value |
|-------|-------|
| **Root** | خ-د-م |
| **Letter** | خ · خاء |
| **Meaning** | serving |
| **Form I** | خدم / يخدم |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |
