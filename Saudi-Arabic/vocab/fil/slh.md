# صلح

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | صلح |
| **Present** | يصلح |
| **Meaning** | fixing / being suitable |
| **Root** | [ص-ل-ح](#roots/slh) |
| **Form** | I · صلح / يصلح · base meaning: fixing / being suitable |

| Arabic | English |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | صلحت | أصلح | بصلح |
| إحنا | صلحنا | نصلح | بنصلح |
| أنت | صلحت | تصلح | بتصلح |
| أنتِ | صلحتي | تصلحين | بتصلحين |
| أنتم | صلحتوا | تصلحون | بتصلحون |
| هو | صلح | يصلح | بيصلح |
| هي | صلحت | تصلح | بتصلح |
| هم | صلحوا | يصلحون | بيصلحون |
