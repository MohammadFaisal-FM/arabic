# مات

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | مات |
| **Present** | يموت |
| **Meaning** | dying |
| **Root** | [م-و-ت](#roots/mwt) |
| **Form** | I · مات / يموت · base meaning: dying |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ماتت | أموت | بموت |
| إحنا | ماتنا | نموت | بنموت |
| أنت | ماتت | تموت | بتموت |
| أنتِ | ماتتي | تموتين | بتموتين |
| أنتم | ماتتوا | تموتون | بتموتون |
| هو | مات | يموت | بيموت |
| هي | ماتت | تموت | بتموت |
| هم | ماتوا | يموتون | بيموتون |
