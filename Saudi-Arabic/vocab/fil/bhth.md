# بحث

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | بحث |
| **Present** | يبحث |
| **Meaning** | searching |
| **Root** | [ب-ح-ث](#roots/bhth) |
| **Form** | I · بحث / يبحث · base meaning: searching |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أبحث عن عمل</span> | <span class="example-en" dir="ltr" lang="en">I’m looking for work</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | بحثت | أبحث | ببحث |
| إحنا | بحثنا | نبحث | بنبحث |
| أنت | بحثت | تبحث | بتبحث |
| أنتِ | بحثتي | تبحثين | بتبحثين |
| أنتم | بحثتوا | تبحثون | بتبحثون |
| هو | بحث | يبحث | بيبحث |
| هي | بحثت | تبحث | بتبحث |
| هم | بحثوا | يبحثون | بيبحثون |
