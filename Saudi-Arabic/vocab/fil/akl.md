# أكل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | أكل |
| **Present** | ياكل |
| **Meaning** | eating / consuming |
| **Root** | [أ-ك-ل](#roots/akl) |
| **Form** | I · أكل / ياكل · base meaning: eating / consuming |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أكلنا رز ودجاج</span> | <span class="example-en" dir="ltr" lang="en">We ate rice and chicken</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | أكلت | أاكل | باكل |
| إحنا | أكلنا | ناكل | بناكل |
| أنت | أكلت | تاكل | بتاكل |
| أنتِ | أكلتي | تاكلين | بتاكلين |
| أنتم | أكلتوا | تاكلون | بتاكلون |
| هو | أكل | ياكل | بياكل |
| هي | أكلت | تاكل | بتاكل |
| هم | أكلوا | ياكلون | بياكلون |
