# فتح

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | فتح |
| **Present** | يفتح |
| **Meaning** | opening |
| **Root** | [ف-ت-ح](#roots/fth) |
| **Form** | I · فتح / يفتح · base meaning: opening |

## Example

| Arabic | English |
|--------|---------|

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | فتحت | أفتح | بفتح |
| إحنا | فتحنا | نفتح | بنفتح |
| أنت | فتحت | تفتح | بتفتح |
| أنتِ | فتحتي | تفتحين | بتفتحين |
| أنتم | فتحتوا | تفتحون | بتفتحون |
| هو | فتح | يفتح | بيفتح |
| هي | فتحت | تفتح | بتفتح |
| هم | فتحوا | يفتحون | بيفتحون |
