# عطى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | عطى |
| **Present** | يعطي |
| **Meaning** | giving |
| **Root** | [ع-ط-ي](#roots/3ty) |
| **Form** | I · عطى / يعطي · base meaning: giving |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | عطىت | أعطي | بعطي |
| إحنا | عطىنا | نعطي | بنعطي |
| أنت | عطىت | تعطي | بتعطي |
| أنتِ | عطىتي | تعطيين | بتعطيين |
| أنتم | عطىتوا | تعطيون | بتعطيون |
| هو | عطى | يعطي | بيعطي |
| هي | عطىت | تعطي | بتعطي |
| هم | عطىوا | يعطيون | بيعطيون |
