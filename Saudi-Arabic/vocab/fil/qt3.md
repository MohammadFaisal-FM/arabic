# قطع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | قطع |
| **Present** | يقطع |
| **Meaning** | cutting |
| **Root** | [ق-ط-ع](#roots/qt3) |
| **Form** | I · قطع / يقطع · base meaning: cutting |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | قطعت | أقطع | بقطع |
| إحنا | قطعنا | نقطع | بنقطع |
| أنت | قطعت | تقطع | بتقطع |
| أنتِ | قطعتي | تقطعين | بتقطعين |
| أنتم | قطعتوا | تقطعون | بتقطعون |
| هو | قطع | يقطع | بيقطع |
| هي | قطعت | تقطع | بتقطع |
| هم | قطعوا | يقطعون | بيقطعون |
