# شغل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | شغل |
| **Present** | يشغل |
| **Meaning** | working / occupying |
| **Root** | [ش-غ-ل](#roots/shghl) |
| **Form** | I · شغل / يشغل · base meaning: working / occupying |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | شغلت | أشغل | بشغل |
| إحنا | شغلنا | نشغل | بنشغل |
| أنت | شغلت | تشغل | بتشغل |
| أنتِ | شغلتي | تشغلين | بتشغلين |
| أنتم | شغلتوا | تشغلون | بتشغلون |
| هو | شغل | يشغل | بيشغل |
| هي | شغلت | تشغل | بتشغل |
| هم | شغلوا | يشغلون | بيشغلون |
