# Lesson 3.4 — Conjugation Basics

## Pronoun order (always use this)

| Arabic | English |
|--------|---------|
| أنا | I |
| إحنا | we |
| أنت | you (m. sg.) |
| أنتِ | you (f. sg.) |
| أنتم | you (pl.) |
| هو | he |
| هي | she |
| هم | they |

---

## Tenses to learn

| Tense | English | Najdi note |
|-------|---------|------------|
| Past | wrote, ate | foundation |
| Present | writes, eats | also "now" |
| Future | will write | **ب** + verb: **ب**جي، **ب**اكل |
| Imperative | write! eat! | command forms |

---

## Priority for family talk

Memorize first: **أنا، أنت، هو، هي، إحنا** — these five cover most home conversation.
