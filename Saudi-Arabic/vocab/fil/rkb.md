# ركب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ركب |
| **Present** | يركب |
| **Meaning** | riding / boarding |
| **Root** | [ر-ك-ب](#roots/rkb) |
| **Form** | I · ركب / يركب · base meaning: riding / boarding |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ركبت | أركب | بركب |
| إحنا | ركبنا | نركب | بنركب |
| أنت | ركبت | تركب | بتركب |
| أنتِ | ركبتي | تركبين | بتركبين |
| أنتم | ركبتوا | تركبون | بتركبون |
| هو | ركب | يركب | بيركب |
| هي | ركبت | تركب | بتركب |
| هم | ركبوا | يركبون | بيركبون |
