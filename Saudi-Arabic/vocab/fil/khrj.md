# خرج

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | خرج |
| **Present** | يخرج |
| **Meaning** | going out |
| **Root** | [خ-ر-ج](#roots/khrj) |
| **Form** | I · خرج / يخرج · base meaning: going out |
