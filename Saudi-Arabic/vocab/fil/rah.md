# راح

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | راح |
| **Present** | يروح |
| **Meaning** | going (Najdi) |
| **Root** | [ر-و-ح](#roots/rah) |
| **Form** | I · راح / يروح |

---

## Example

| Arabic · English |
|------------------|
| أروح السوق — I’m going to the market |

---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | راحت | أروح | بروح |
| إحنا | راحنا | نروح | بنروح |
| أنت | راحت | تروح | بتروح |
| أنتِ | راحتي | تروحين | بتروحين |
| أنتم | راحتوا | تروحون | بتروحون |
| هو | راح | يروح | بيروح |
| هي | راحت | تروح | بتروح |
| هم | راحوا | يروحون | بيروحون |
