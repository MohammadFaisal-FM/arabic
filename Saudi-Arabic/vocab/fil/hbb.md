# حبّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | حبّ |
| **Present** | يحب |
| **Meaning** | loving |
| **Root** | [ح-ب-ب](#roots/hbb) |
| **Form** | I · حبّ / يحب · base meaning: loving |

| Arabic | English |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | حبّت | أحب | بحب |
| إحنا | حبّنا | نحب | بنحب |
| أنت | حبّت | تحب | بتحب |
| أنتِ | حبّتي | تحبين | بتحبين |
| أنتم | حبّتوا | تحبون | بتحبون |
| هو | حبّ | يحب | بيحب |
| هي | حبّت | تحب | بتحب |
| هم | حبّوا | يحبون | بيحبون |
