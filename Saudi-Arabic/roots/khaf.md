# خ-و-ف

| Field | Value |
|-------|-------|
| **Root** | خ-و-ف |
| **Letter** | خ · خاء |
| **Meaning** | fearing |
| **Form I** | خاف / يخاف |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

---

## Example

| Arabic · English |
|------------------|
| ما أخاف — I’m not afraid |
