# رجع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | رجع |
| **Present** | يرجع |
| **Meaning** | returning |
| **Root** | [ر-ج-ع](#roots/rj3) |
| **Form** | I · رجع / يرجع · base meaning: returning |

## Example

| Arabic | English |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | رجعت | أرجع | برجع |
| إحنا | رجعنا | نرجع | بنرجع |
| أنت | رجعت | ترجع | بترجع |
| أنتِ | رجعتي | ترجعين | بترجعين |
| أنتم | رجعتوا | ترجعون | بترجعون |
| هو | رجع | يرجع | بيرجع |
| هي | رجعت | ترجع | بترجع |
| هم | رجعوا | يرجعون | بيرجعون |
