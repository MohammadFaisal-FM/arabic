# حطّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | حطّ |
| **Present** | يحط |
| **Meaning** | putting / placing |
| **Root** | [ح-ط-ط](#roots/htt) |
| **Form** | I · حطّ / يحط · base meaning: putting / placing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">حطها هنا</span> | <span class="example-en" dir="ltr" lang="en">Put it here</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | حطّت | أحط | بحط |
| إحنا | حطّنا | نحط | بنحط |
| أنت | حطّت | تحط | بتحط |
| أنتِ | حطّتي | تحطين | بتحطين |
| أنتم | حطّتوا | تحطون | بتحطون |
| هو | حطّ | يحط | بيحط |
| هي | حطّت | تحط | بتحط |
| هم | حطّوا | يحطون | بيحطون |
