# زاد

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | زاد |
| **Present** | يزيد |
| **Meaning** | increasing |
| **Root** | [ز-ي-د](#roots/zyd) |
| **Form** | I · زاد / يزيد · base meaning: increasing |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | زادت | أزيد | بزيد |
| إحنا | زادنا | نزيد | بنزيد |
| أنت | زادت | تزيد | بتزيد |
| أنتِ | زادتي | تزيدين | بتزيدين |
| أنتم | زادتوا | تزيدون | بتزيدون |
| هو | زاد | يزيد | بيزيد |
| هي | زادت | تزيد | بتزيد |
| هم | زادوا | يزيدون | بيزيدون |
