# هدى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | هدى |
| **Present** | يهدي |
| **Meaning** | calming / guiding |
| **Root** | [ه-د-ي](#roots/hdy) |
| **Form** | I · هدى / يهدي · base meaning: calming / guiding |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | هدىت | أهدي | بهدي |
| إحنا | هدىنا | نهدي | بنهدي |
| أنت | هدىت | تهدي | بتهدي |
| أنتِ | هدىتي | تهديين | بتهديين |
| أنتم | هدىتوا | تهديون | بتهديون |
| هو | هدى | يهدي | بيهدي |
| هي | هدىت | تهدي | بتهدي |
| هم | هدىوا | يهديون | بيهديون |
