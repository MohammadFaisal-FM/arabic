# دفع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | دفع |
| **Present** | يدفع |
| **Meaning** | paying / pushing |
| **Root** | [د-ف-ع](#roots/df3) |
| **Form** | I · دفع / يدفع · base meaning: paying / pushing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">دفعت الحساب</span> | <span class="example-en" dir="ltr" lang="en">I paid the bill</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | دفعت | أدفع | بدفع |
| إحنا | دفعنا | ندفع | بندفع |
| أنت | دفعت | تدفع | بتدفع |
| أنتِ | دفعتي | تدفعين | بتدفعين |
| أنتم | دفعتوا | تدفعون | بتدفعون |
| هو | دفع | يدفع | بيدفع |
| هي | دفعت | تدفع | بتدفع |
| هم | دفعوا | يدفعون | بيدفعون |
