# قال

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | قال |
| **Present** | يقول |
| **Meaning** | saying |
| **Root** | [ق-و-ل](#roots/qwl) |
| **Form** | I · قال / يقول · base meaning: saying |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">وش قلت؟</span> | <span class="example-en" dir="ltr" lang="en">What did you say?</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | قالت | أقول | بقول |
| إحنا | قالنا | نقول | بنقول |
| أنت | قالت | تقول | بتقول |
| أنتِ | قالتي | تقولين | بتقولين |
| أنتم | قالتوا | تقولون | بتقولون |
| هو | قال | يقول | بيقول |
| هي | قالت | تقول | بتقول |
| هم | قالوا | يقولون | بيقولون |
