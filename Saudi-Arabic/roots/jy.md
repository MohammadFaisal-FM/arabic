# ج-ي-ء

| Field | Value |
|-------|-------|
| **Root** | ج-ي-ء |
| **Letter** | ج · جيم |
| **Meaning** | coming |
| **Form I** | جا / يجي |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

## Example

| Arabic · English |
|------------------|
| بجي بعدين — I’ll come later |
