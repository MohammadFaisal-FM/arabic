# طول

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | طول |
| **Present** | يطول |
| **Meaning** | taking long / being tall |
| **Root** | [ط-و-ل](#roots/twl) |
| **Form** | I · طول / يطول · base meaning: taking long / being tall |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">لا تطول</span> | <span class="example-en" dir="ltr" lang="en">Don’t take long</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | طولت | أطول | بطول |
| إحنا | طولنا | نطول | بنطول |
| أنت | طولت | تطول | بتطول |
| أنتِ | طولتي | تطولين | بتطولين |
| أنتم | طولتوا | تطولون | بتطولون |
| هو | طول | يطول | بيطول |
| هي | طولت | تطول | بتطول |
| هم | طولوا | يطولون | بيطولون |
