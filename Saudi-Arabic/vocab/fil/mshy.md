# مشى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | مشى |

| **Meaning** | walking |
| **Root** | [م-ش-ي](#roots/mshy) |
| **Form** | I · مشى / يمشي · base meaning: walking |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | مشىت | أمشي | بمشي |
| إحنا | مشىنا | نمشي | بنمشي |
| أنت | مشىت | تمشي | بتمشي |
| أنتِ | مشىتي | تمشيين | بتمشيين |
| أنتم | مشىتوا | تمشيون | بتمشيون |
| هو | مشى | يمشي | بيمشي |
| هي | مشىت | تمشي | بتمشي |
| هم | مشىوا | يمشيون | بيمشيون |
