# شرى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | شرى |
| **Present** | يشري |
| **Meaning** | buying |
| **Root** | [ش-ر-ي](#roots/shry) |
| **Form** | I · شرى / يشري · base meaning: buying |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">شريت أكل</span> | <span class="example-en" dir="ltr" lang="en">I bought food</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | شرىت | أشري | بشري |
| إحنا | شرىنا | نشري | بنشري |
| أنت | شرىت | تشري | بتشري |
| أنتِ | شرىتي | تشريين | بتشريين |
| أنتم | شرىتوا | تشريون | بتشريون |
| هو | شرى | يشري | بيشري |
| هي | شرىت | تشري | بتشري |
| هم | شرىوا | يشريون | بيشريون |
