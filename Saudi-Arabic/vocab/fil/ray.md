# رأى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | رأى |
| **Present** | يرى |
| **Meaning** | seeing |
| **Root** | [ر-ا-ي](#roots/ray) |
| **Form** | I · رأى / يرى · base meaning: seeing |

---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | رأىت | أرى | برى |
| إحنا | رأىنا | نرى | بنرى |
| أنت | رأىت | ترى | بترى |
| أنتِ | رأىتي | ترىين | بترىين |
| أنتم | رأىتوا | ترىون | بترىون |
| هو | رأى | يرى | بيرى |
| هي | رأىت | ترى | بترى |
| هم | رأىوا | يرىون | بيرىون |
