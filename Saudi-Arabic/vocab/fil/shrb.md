# شرب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | شرب |
| **Present** | يشرب |
| **Meaning** | drinking |
| **Root** | [ش-ر-ب](#roots/shrb) |
| **Form** | I · شرب / يشرب · base meaning: drinking |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | شربت | أشرب | بشرب |
| إحنا | شربنا | نشرب | بنشرب |
| أنت | شربت | تشرب | بتشرب |
| أنتِ | شربتي | تشربين | بتشربين |
| أنتم | شربتوا | تشربون | بتشربون |
| هو | شرب | يشرب | بيشرب |
| هي | شربت | تشرب | بتشرب |
| هم | شربوا | يشربون | بيشربون |
