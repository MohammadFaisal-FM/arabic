# شاف

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | شاف |
| **Present** | يشوف |
| **Meaning** | seeing (Najdi) |
| **Root** | [ش-و-ف](#roots/shaf) |
| **Form** | I · شاف / يشوف · base meaning: seeing (Najdi) |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أشوفك بكرة</span> | <span class="example-en" dir="ltr" lang="en">I’ll see you tomorrow</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | شافت | أشوف | بشوف |
| إحنا | شافنا | نشوف | بنشوف |
| أنت | شافت | تشوف | بتشوف |
| أنتِ | شافتي | تشوفين | بتشوفين |
| أنتم | شافتوا | تشوفون | بتشوفون |
| هو | شاف | يشوف | بيشوف |
| هي | شافت | تشوف | بتشوف |
| هم | شافوا | يشوفون | بيشوفون |
