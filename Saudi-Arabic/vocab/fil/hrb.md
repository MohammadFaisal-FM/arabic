# هرب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | هرب |
| **Present** | يهرب |
| **Meaning** | escaping / running away |
| **Root** | [ه-ر-ب](#roots/hrb) |
| **Form** | I · هرب / يهرب · base meaning: escaping / running away |

## Example

| Arabic | English |
|--------|---------|

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | هربت | أهرب | بهرب |
| إحنا | هربنا | نهرب | بنهرب |
| أنت | هربت | تهرب | بتهرب |
| أنتِ | هربتي | تهربين | بتهربين |
| أنتم | هربتوا | تهربون | بتهربون |
| هو | هرب | يهرب | بيهرب |
| هي | هربت | تهرب | بتهرب |
| هم | هربوا | يهربون | بيهربون |
