# سأل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | سأل |
| **Present** | يسأل |
| **Meaning** | asking |
| **Root** | [س-أ-ل](#roots/sal) |
| **Form** | I · سأل / يسأل · base meaning: asking |

| Arabic | English |
|--------|---------|

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | سألت | أسأل | بسأل |
| إحنا | سألنا | نسأل | بنسأل |
| أنت | سألت | تسأل | بتسأل |
| أنتِ | سألتي | تسألين | بتسألين |
| أنتم | سألتوا | تسألون | بتسألون |
| هو | سأل | يسأل | بيسأل |
| هي | سألت | تسأل | بتسأل |
| هم | سألوا | يسألون | بيسألون |
