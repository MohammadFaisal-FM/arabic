# غاب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | غاب |
| **Present** | يغيب |
| **Meaning** | being absent |
| **Root** | [غ-ي-ب](#roots/ghyb) |
| **Form** | I · غاب / يغيب · base meaning: being absent |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | غابت | أغيب | بغيب |
| إحنا | غابنا | نغيب | بنغيب |
| أنت | غابت | تغيب | بتغيب |
| أنتِ | غابتي | تغيبين | بتغيبين |
| أنتم | غابتوا | تغيبون | بتغيبون |
| هو | غاب | يغيب | بيغيب |
| هي | غابت | تغيب | بتغيب |
| هم | غابوا | يغيبون | بيغيبون |
