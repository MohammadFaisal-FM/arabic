# سار

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | سار |
| **Present** | يسير |
| **Meaning** | walking / going |
| **Root** | [س-ي-ر](#roots/syr) |
| **Form** | I · سار / يسير · base meaning: walking / going |

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">سر معي</span> | <span class="example-en" dir="ltr" lang="en">Walk with me</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | سارت | أسير | بسير |
| إحنا | سارنا | نسير | بنسير |
| أنت | سارت | تسير | بتسير |
| أنتِ | سارتي | تسيرين | بتسيرين |
| أنتم | سارتوا | تسيرون | بتسيرون |
| هو | سار | يسير | بيسير |
| هي | سارت | تسير | بتسير |
| هم | ساروا | يسيرون | بيسيرون |
