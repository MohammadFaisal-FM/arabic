# Lesson 6.2 — Passage Translation Method

## The `passage` / `maqta` exercise

1. You get a **3–4 sentence English** passage (Easy / Medium / Hard)
2. Key words marked: [called / اتصل]
3. You translate to **Najdi**
4. Tutor gives: model answer, corrections, Sarf breakdown, new vocab

---

## Method (English speaker workflow)

| Step | Action |
|------|--------|
| 1 | Read English; note bracketed Arabic hints |
| 2 | Draft Najdi — use **ب** for future, **أهل** for family |
| 3 | Compare with a model answer (or ask a tutor) |
| 4 | **Rewrite once** with corrections — don't skip |
| 5 | New verbs → note in [verb-root-tracker.md](../../verb-root-tracker.md) |
