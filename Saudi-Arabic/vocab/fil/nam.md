# نام

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | نام |
| **Present** | ينام |
| **Meaning** | sleeping |
| **Root** | [ن-و-م](#roots/nam) |
| **Form** | I · نام / ينام · base meaning: sleeping |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أنام بدري</span> | <span class="example-en" dir="ltr" lang="en">I sleep early</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | نامت | أنام | بنام |
| إحنا | نامنا | ننام | بننام |
| أنت | نامت | تنام | بتنام |
| أنتِ | نامتي | تنامين | بتنامين |
| أنتم | نامتوا | تنامون | بتنامون |
| هو | نام | ينام | بينام |
| هي | نامت | تنام | بتنام |
| هم | ناموا | ينامون | بينامون |
