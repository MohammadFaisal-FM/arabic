# ف-ت-ح

| Field | Value |
|-------|-------|
| **Root** | ف-ت-ح |
| **Letter** | ف · فاء |
| **Meaning** | opening |
| **Form I** | فتح / يفتح |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

---

## Example

| Arabic · English |
|------------------|
| افتح الباب — Open the door |
