# ترك

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ترك |
| **Present** | يترك |
| **Meaning** | leaving |
| **Root** | [ت-ر-ك](#roots/trk) |
| **Form** | I · ترك / يترك · base meaning: leaving |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | تركت | أترك | بترك |
| إحنا | تركنا | نترك | بنترك |
| أنت | تركت | تترك | بتترك |
| أنتِ | تركتي | تتركين | بتتركين |
| أنتم | تركتوا | تتركون | بتتركون |
| هو | ترك | يترك | بيترك |
| هي | تركت | تترك | بتترك |
| هم | تركوا | يتركون | بيتركون |
