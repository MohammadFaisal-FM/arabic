# ظهر

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ظهر |
| **Present** | يظهر |
| **Meaning** | appearing |
| **Root** | [ظ-ه-ر](#roots/zhr) |
| **Form** | I · ظهر / يظهر · base meaning: appearing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">ظهر الحل</span> | <span class="example-en" dir="ltr" lang="en">The solution appeared</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ظهرت | أظهر | بظهر |
| إحنا | ظهرنا | نظهر | بنظهر |
| أنت | ظهرت | تظهر | بتظهر |
| أنتِ | ظهرتي | تظهرين | بتظهرين |
| أنتم | ظهرتوا | تظهرون | بتظهرون |
| هو | ظهر | يظهر | بيظهر |
| هي | ظهرت | تظهر | بتظهر |
| هم | ظهروا | يظهرون | بيظهرون |
