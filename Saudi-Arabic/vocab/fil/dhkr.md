| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ذكر |

| **Meaning** | mentioning / remembering |
| **Root** | [ذ-ك-ر](#roots/dhkr) |
| **Form** | I · ذكر / يذكر · base meaning: mentioning / remembering |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ذكرت | أذكر | بذكر |
| إحنا | ذكرنا | نذكر | بنذكر |
| أنت | ذكرت | تذكر | بتذكر |
| أنتِ | ذكرتي | تذكرين | بتذكرين |
| أنتم | ذكرتوا | تذكرون | بتذكرون |
| هو | ذكر | يذكر | بيذكر |
| هي | ذكرت | تذكر | بتذكر |
| هم | ذكروا | يذكرون | بيذكرون |
