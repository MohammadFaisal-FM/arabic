# كسر

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | كسر |
| **Present** | يكسر |
| **Meaning** | breaking |
| **Root** | [ك-س-ر](#roots/ksr) |
| **Form** | I · كسر / يكسر · base meaning: breaking |

| Arabic | English |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | كسرت | أكسر | بكسر |
| إحنا | كسرنا | نكسر | بنكسر |
| أنت | كسرت | تكسر | بتكسر |
| أنتِ | كسرتي | تكسرين | بتكسرين |
| أنتم | كسرتوا | تكسرون | بتكسرون |
| هو | كسر | يكسر | بيكسر |
| هي | كسرت | تكسر | بتكسر |
| هم | كسروا | يكسرون | بيكسرون |
