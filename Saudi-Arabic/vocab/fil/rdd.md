# ردّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ردّ |
| **Present** | يرد |
| **Meaning** | replying / returning |
| **Root** | [ر-د-د](#roots/rdd) |
| **Form** | I · ردّ / يرد · base meaning: replying / returning |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">رد عليّ</span> | <span class="example-en" dir="ltr" lang="en">Reply to me</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ردّت | أرد | برد |
| إحنا | ردّنا | نرد | بنرد |
| أنت | ردّت | ترد | بترد |
| أنتِ | ردّتي | تردين | بتردين |
| أنتم | ردّتوا | تردون | بتردون |
| هو | ردّ | يرد | بيرد |
| هي | ردّت | ترد | بترد |
| هم | ردّوا | يردون | بيردون |
