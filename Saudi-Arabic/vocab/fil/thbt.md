# ثبت

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ثبت |
| **Present** | يثبت |
| **Meaning** | staying firm / proving |
| **Root** | [ث-ب-ت](#roots/thbt) |
| **Form** | I · ثبت / يثبت · base meaning: staying firm / proving |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ثبتت | أثبت | بثبت |
| إحنا | ثبتنا | نثبت | بنثبت |
| أنت | ثبتت | تثبت | بتثبت |
| أنتِ | ثبتتي | تثبتين | بتثبتين |
| أنتم | ثبتتوا | تثبتون | بتثبتون |
| هو | ثبت | يثبت | بيثبت |
| هي | ثبتت | تثبت | بتثبت |
| هم | ثبتوا | يثبتون | بيثبتون |
