# عاش

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | عاش |
| **Present** | يعيش |
| **Meaning** | living |
| **Root** | [ع-ي-ش](#roots/3ysh) |
| **Form** | I · عاش / يعيش · base meaning: living |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أعيش هنا</span> | <span class="example-en" dir="ltr" lang="en">I live here</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | عاشت | أعيش | بعيش |
| إحنا | عاشنا | نعيش | بنعيش |
| أنت | عاشت | تعيش | بتعيش |
| أنتِ | عاشتي | تعيشين | بتعيشين |
| أنتم | عاشتوا | تعيشون | بتعيشون |
| هو | عاش | يعيش | بيعيش |
| هي | عاشت | تعيش | بتعيش |
| هم | عاشوا | يعيشون | بيعيشون |
