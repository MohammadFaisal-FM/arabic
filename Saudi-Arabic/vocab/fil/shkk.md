# شكّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | شكّ |
| **Present** | يشك |
| **Meaning** | doubting |
| **Root** | [ش-ك-ك](#roots/shkk) |
| **Form** | I · شكّ / يشك · base meaning: doubting |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">ما أشك</span> | <span class="example-en" dir="ltr" lang="en">I don’t doubt</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | شكّت | أشك | بشك |
| إحنا | شكّنا | نشك | بنشك |
| أنت | شكّت | تشك | بتشك |
| أنتِ | شكّتي | تشكين | بتشكين |
| أنتم | شكّتوا | تشكون | بتشكون |
| هو | شكّ | يشك | بيشك |
| هي | شكّت | تشك | بتشك |
| هم | شكّوا | يشكون | بيشكون |
