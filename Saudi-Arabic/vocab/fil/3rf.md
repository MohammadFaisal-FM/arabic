# عرف

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | عرف |
| **Present** | يعرف |
| **Meaning** | knowing |
| **Root** | [ع-ر-ف](#roots/3rf) |
| **Form** | I · عرف / يعرف · base meaning: knowing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أعرف الطريق</span> | <span class="example-en" dir="ltr" lang="en">I know the way</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | عرفت | أعرف | بعرف |
| إحنا | عرفنا | نعرف | بنعرف |
| أنت | عرفت | تعرف | بتعرف |
| أنتِ | عرفتي | تعرفين | بتعرفين |
| أنتم | عرفتوا | تعرفون | بتعرفون |
| هو | عرف | يعرف | بيعرف |
| هي | عرفت | تعرف | بتعرف |
| هم | عرفوا | يعرفون | بيعرفون |
