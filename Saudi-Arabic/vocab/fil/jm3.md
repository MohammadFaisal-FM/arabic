# جمع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | جمع |
| **Present** | يجمع |
| **Meaning** | gathering |
| **Root** | [ج-م-ع](#roots/jm3) |
| **Form** | I · جمع / يجمع · base meaning: gathering |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | جمعت | أجمع | بجمع |
| إحنا | جمعنا | نجمع | بنجمع |
| أنت | جمعت | تجمع | بتجمع |
| أنتِ | جمعتي | تجمعين | بتجمعين |
| أنتم | جمعتوا | تجمعون | بتجمعون |
| هو | جمع | يجمع | بيجمع |
| هي | جمعت | تجمع | بتجمع |
| هم | جمعوا | يجمعون | بيجمعون |
