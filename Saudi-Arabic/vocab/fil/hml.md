# حمل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | حمل |
| **Present** | يحمل |
| **Meaning** | carrying |
| **Root** | [ح-م-ل](#roots/hml) |
| **Form** | I · حمل / يحمل · base meaning: carrying |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">احمل الشنطة</span> | <span class="example-en" dir="ltr" lang="en">Carry the bag</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | حملت | أحمل | بحمل |
| إحنا | حملنا | نحمل | بنحمل |
| أنت | حملت | تحمل | بتحمل |
| أنتِ | حملتي | تحملين | بتحملين |
| أنتم | حملتوا | تحملون | بتحملون |
| هو | حمل | يحمل | بيحمل |
| هي | حملت | تحمل | بتحمل |
| هم | حملوا | يحملون | بيحملون |
