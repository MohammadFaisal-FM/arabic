# طلع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | طلع |
| **Present** | يطلع |
| **Meaning** | going up / coming out |
| **Root** | [ط-ل-ع](#roots/tl3) |
| **Form** | I · طلع / يطلع · base meaning: going up / coming out |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | طلعت | أطلع | بطلع |
| إحنا | طلعنا | نطلع | بنطلع |
| أنت | طلعت | تطلع | بتطلع |
| أنتِ | طلعتي | تطلعين | بتطلعين |
| أنتم | طلعتوا | تطلعون | بتطلعون |
| هو | طلع | يطلع | بيطلع |
| هي | طلعت | تطلع | بتطلع |
| هم | طلعوا | يطلعون | بيطلعون |
