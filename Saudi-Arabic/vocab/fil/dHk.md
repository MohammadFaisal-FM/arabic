# ضحك

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ضحك |
| **Present** | يضحك |
| **Meaning** | laughing |
| **Root** | [ض-ح-ك](#roots/dHk) |
| **Form** | I · ضحك / يضحك · base meaning: laughing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">يضحك كثير</span> | <span class="example-en" dir="ltr" lang="en">He laughs a lot</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ضحكت | أضحك | بضحك |
| إحنا | ضحكنا | نضحك | بنضحك |
| أنت | ضحكت | تضحك | بتضحك |
| أنتِ | ضحكتي | تضحكين | بتضحكين |
| أنتم | ضحكتوا | تضحكون | بتضحكون |
| هو | ضحك | يضحك | بيضحك |
| هي | ضحكت | تضحك | بتضحك |
| هم | ضحكوا | يضحكون | بيضحكون |
