# كبر

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | كبر |
| **Present** | يكبر |
| **Meaning** | growing / being big |
| **Root** | [ك-ب-ر](#roots/kbr) |
| **Form** | I · كبر / يكبر · base meaning: growing / being big |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">كبر الولد</span> | <span class="example-en" dir="ltr" lang="en">The boy grew up</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | كبرت | أكبر | بكبر |
| إحنا | كبرنا | نكبر | بنكبر |
| أنت | كبرت | تكبر | بتكبر |
| أنتِ | كبرتي | تكبرين | بتكبرين |
| أنتم | كبرتوا | تكبرون | بتكبرون |
| هو | كبر | يكبر | بيكبر |
| هي | كبرت | تكبر | بتكبر |
| هم | كبروا | يكبرون | بيكبرون |
