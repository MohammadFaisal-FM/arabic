# زار

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | زار |
| **Present** | يزور |
| **Meaning** | visiting |
| **Root** | [ز-و-ر](#roots/zwr) |
| **Form** | I · زار / يزور · base meaning: visiting |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">بزور أهلي</span> | <span class="example-en" dir="ltr" lang="en">I’ll visit my family</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | زارت | أزور | بزور |
| إحنا | زارنا | نزور | بنزور |
| أنت | زارت | تزور | بتزور |
| أنتِ | زارتي | تزورين | بتزورين |
| أنتم | زارتوا | تزورون | بتزورون |
| هو | زار | يزور | بيزور |
| هي | زارت | تزور | بتزور |
| هم | زاروا | يزورون | بيزورون |
