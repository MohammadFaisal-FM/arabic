# ولد

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ولد |
| **Present** | يولد |
| **Meaning** | being born / giving birth |
| **Root** | [و-ل-د](#roots/wld) |
| **Form** | I · ولد / يولد · base meaning: being born / giving birth |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">ولد في الرياض</span> | <span class="example-en" dir="ltr" lang="en">He was born in Riyadh</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ولدت | أألد | بألد |
| إحنا | ولدنا | نألد | بنألد |
| أنت | ولدت | تألد | بتألد |
| أنتِ | ولدتي | تألدين | بتألدين |
| أنتم | ولدتوا | تألدون | بتألدون |
| هو | ولد | يألد | بيألد |
| هي | ولدت | تألد | بتألد |
| هم | ولدوا | يألدون | بيألدون |
