# سكن

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | سكن |
| **Present** | يسكن |
| **Meaning** | living / residing |
| **Root** | [س-ك-ن](#roots/skn) |
| **Form** | I · سكن / يسكن · base meaning: living / residing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أسكن في الرياض</span> | <span class="example-en" dir="ltr" lang="en">I live in Riyadh</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | سكنت | أسكن | بسكن |
| إحنا | سكننا | نسكن | بنسكن |
| أنت | سكنت | تسكن | بتسكن |
| أنتِ | سكنتي | تسكنين | بتسكنين |
| أنتم | سكنتوا | تسكنون | بتسكنون |
| هو | سكن | يسكن | بيسكن |
| هي | سكنت | تسكن | بتسكن |
| هم | سكنوا | يسكنون | بيسكنون |
