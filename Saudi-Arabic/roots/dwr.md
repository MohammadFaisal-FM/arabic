# د-و-ر

| Field | Value |
|-------|-------|
| **Root** | د-و-ر |
| **Letter** | د · دال |
| **Meaning** | turning / looking for |
| **Form I** | دار / يدور |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

## Example

| Arabic · English |
|------------------|
| أدور على مفتاح — I’m looking for a key |
