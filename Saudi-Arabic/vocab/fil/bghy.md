# بغى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | بغى |
| **Present** | يبغى |
| **Meaning** | wanting (Najdi) |
| **Root** | [ب-غ-ي](#roots/bghy) |
| **Form** | I · بغى / يبغى · base meaning: wanting (Najdi) |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أبغى قهوة</span> | <span class="example-en" dir="ltr" lang="en">I want coffee</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | بغىت | أبغى | ببغى |
| إحنا | بغىنا | نبغى | بنبغى |
| أنت | بغىت | تبغى | بتبغى |
| أنتِ | بغىتي | تبغىين | بتبغىين |
| أنتم | بغىتوا | تبغىون | بتبغىون |
| هو | بغى | يبغى | بيبغى |
| هي | بغىت | تبغى | بتبغى |
| هم | بغىوا | يبغىون | بيبغىون |
