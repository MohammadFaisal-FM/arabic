# أ-م-ر

| Field | Value |
|-------|-------|
| **Root** | أ-م-ر |
| **Letter** | أ · ألف |
| **Meaning** | ordering / commanding |
| **Form I** | أمر / يأمر |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

---

## Example

| Arabic · English |
|------------------|
| أمرني أسويها — He told me to do it |
