# اتّبع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | اتّبع |
| **Present** | يتّبع |
| **Meaning** | following · follow |
| **Root** | [ت-ب-ع](#roots/tb3) |
| **Form** | VIII · اتّبع / يتّبع · follow |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | اتّبعت | أتّبع | بتّبع |
| إحنا | اتّبعنا | نتّبع | بنتّبع |
| أنت | اتّبعت | تتّبع | بتتّبع |
| أنتِ | اتّبعتي | تتّبعين | بتتّبعين |
| أنتم | اتّبعتوا | تتّبعون | بتتّبعون |
| هو | اتّبع | يتّبع | بيتّبع |
| هي | اتّبعت | تتّبع | بتتّبع |
| هم | اتّبعوا | يتّبعون | بيتّبعون |
