# خدم

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | خدم |
| **Present** | يخدم |
| **Meaning** | serving |
| **Root** | [خ-د-م](#roots/khdm) |
| **Form** | I · خدم / يخدم · base meaning: serving |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | خدمت | أخدم | بخدم |
| إحنا | خدمنا | نخدم | بنخدم |
| أنت | خدمت | تخدم | بتخدم |
| أنتِ | خدمتي | تخدمين | بتخدمين |
| أنتم | خدمتوا | تخدمون | بتخدمون |
| هو | خدم | يخدم | بيخدم |
| هي | خدمت | تخدم | بتخدم |
| هم | خدموا | يخدمون | بيخدمون |
