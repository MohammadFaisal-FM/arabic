# نقل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | نقل |
| **Present** | ينقل |
| **Meaning** | moving / transferring |
| **Root** | [ن-ق-ل](#roots/nql) |
| **Form** | I · نقل / ينقل · base meaning: moving / transferring |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | نقلت | أنقل | بنقل |
| إحنا | نقلنا | ننقل | بننقل |
| أنت | نقلت | تنقل | بتنقل |
| أنتِ | نقلتي | تنقلين | بتنقلين |
| أنتم | نقلتوا | تنقلون | بتنقلون |
| هو | نقل | ينقل | بينقل |
| هي | نقلت | تنقل | بتنقل |
| هم | نقلوا | ينقلون | بينقلون |
