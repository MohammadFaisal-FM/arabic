| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | زار |
| **Present** | يزور |
| **Meaning** | visiting |
| **Root** | [ز-و-ر](#roots/zwr) |
| **Form** | I · زار / يزور · base meaning: visiting |
