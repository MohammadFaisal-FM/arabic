# لبس

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | لبس |
| **Present** | يلبس |
| **Meaning** | wearing / dressing |
| **Root** | [ل-ب-س](#roots/lbs) |
| **Form** | I · لبس / يلبس · base meaning: wearing / dressing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">وش تلبس؟</span> | <span class="example-en" dir="ltr" lang="en">What are you wearing?</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | لبست | ألبس | بلبس |
| إحنا | لبسنا | نلبس | بنلبس |
| أنت | لبست | تلبس | بتلبس |
| أنتِ | لبستي | تلبسين | بتلبسين |
| أنتم | لبستوا | تلبسون | بتلبسون |
| هو | لبس | يلبس | بيلبس |
| هي | لبست | تلبس | بتلبس |
| هم | لبسوا | يلبسون | بيلبسون |
