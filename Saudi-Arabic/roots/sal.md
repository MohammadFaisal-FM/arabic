# س-أ-ل

| Field | Value |
|-------|-------|
| **Root** | س-أ-ل |
| **Letter** | س · سين |
| **Meaning** | asking |
| **Form I** | سأل / يسأل |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

## Example

| Arabic · English |
|------------------|
| أسألك سؤال — Can I ask you something? |
