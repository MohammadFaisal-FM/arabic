# ش-غ-ل

| Field | Value |
|-------|-------|
| **Root** | ش-غ-ل |
| **Letter** | ش · شين |
| **Meaning** | working / occupying |
| **Form I** | شغل / يشغل |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

---

## Example

| Arabic · English |
|------------------|
