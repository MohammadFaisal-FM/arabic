# خ-ل-ص

| Field | Value |
|-------|-------|
| **Root** | خ-ل-ص |
| **Letter** | خ · خاء |
| **Meaning** | finishing |
| **Form I** | خلص / يخلص |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

## Example
