# دفع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | دفع |
| **Present** | يدفع |
| **Meaning** | paying / pushing |
| **Root** | [د-ف-ع](#roots/df3) |
| **Form** | I · دفع / يدفع · base meaning: paying / pushing |
