# ر-د-د

| Field | Value |
|-------|-------|
| **Root** | ر-د-د |
| **Letter** | ر · راء |
| **Meaning** | replying / returning |
| **Form I** | ردّ / يرد |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |
