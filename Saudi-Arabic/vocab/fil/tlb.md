# طلب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | طلب |
| **Present** | يطلب |
| **Meaning** | requesting / ordering |
| **Root** | [ط-ل-ب](#roots/tlb) |
| **Form** | I · طلب / يطلب · base meaning: requesting / ordering |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">طلبت قهوة</span> | <span class="example-en" dir="ltr" lang="en">I ordered coffee</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | طلبت | أطلب | بطلب |
| إحنا | طلبنا | نطلب | بنطلب |
| أنت | طلبت | تطلب | بتطلب |
| أنتِ | طلبتي | تطلبين | بتطلبين |
| أنتم | طلبتوا | تطلبون | بتطلبون |
| هو | طلب | يطلب | بيطلب |
| هي | طلبت | تطلب | بتطلب |
| هم | طلبوا | يطلبون | بيطلبون |
