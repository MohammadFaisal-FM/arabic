# لعب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | لعب |
| **Present** | يلعب |
| **Meaning** | playing |
| **Root** | [ل-ع-ب](#roots/l3b) |
| **Form** | I · لعب / يلعب · base meaning: playing |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | لعبت | ألعب | بلعب |
| إحنا | لعبنا | نلعب | بنلعب |
| أنت | لعبت | تلعب | بتلعب |
| أنتِ | لعبتي | تلعبين | بتلعبين |
| أنتم | لعبتوا | تلعبون | بتلعبون |
| هو | لعب | يلعب | بيلعب |
| هي | لعبت | تلعب | بتلعب |
| هم | لعبوا | يلعبون | بيلعبون |
