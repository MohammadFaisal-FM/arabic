# ضاق

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ضاق |
| **Present** | يضيق |
| **Meaning** | being tight / annoyed |
| **Root** | [ض-ي-ق](#roots/dyq) |
| **Form** | I · ضاق / يضيق · base meaning: being tight / annoyed |

## Example

| Arabic | English |
|--------|---------|

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ضاقت | أضيق | بضيق |
| إحنا | ضاقنا | نضيق | بنضيق |
| أنت | ضاقت | تضيق | بتضيق |
| أنتِ | ضاقتي | تضيقين | بتضيقين |
| أنتم | ضاقتوا | تضيقون | بتضيقون |
| هو | ضاق | يضيق | بيضيق |
| هي | ضاقت | تضيق | بتضيق |
| هم | ضاقوا | يضيقون | بيضيقون |
