# ع-م-ل

| Field | Value |
|-------|-------|
| **Root** | ع-م-ل |
| **Letter** | ع · عين |
| **Meaning** | working / doing |
| **Form I** | عمل / يعمل |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |
