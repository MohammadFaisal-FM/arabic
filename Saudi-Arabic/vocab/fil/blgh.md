# بلغ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | بلغ |
| **Present** | يبلغ |
| **Meaning** | reaching / informing |
| **Root** | [ب-ل-غ](#roots/blgh) |
| **Form** | I · بلغ / يبلغ · base meaning: reaching / informing |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | بلغت | أبلغ | ببلغ |
| إحنا | بلغنا | نبلغ | بنبلغ |
| أنت | بلغت | تبلغ | بتبلغ |
| أنتِ | بلغتي | تبلغين | بتبلغين |
| أنتم | بلغتوا | تبلغون | بتبلغون |
| هو | بلغ | يبلغ | بيبلغ |
| هي | بلغت | تبلغ | بتبلغ |
| هم | بلغوا | يبلغون | بيبلغون |
