# نسي

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | نسي |
| **Present** | ينسى |
| **Meaning** | forgetting |
| **Root** | [ن-س-ي](#roots/nsy) |
| **Form** | I · نسي / ينسى · base meaning: forgetting |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">نسيت اسمه</span> | <span class="example-en" dir="ltr" lang="en">I forgot his name</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | نسيت | أنسى | بنسى |
| إحنا | نسينا | ننسى | بننسى |
| أنت | نسيت | تنسى | بتنسى |
| أنتِ | نسيتي | تنسىين | بتنسىين |
| أنتم | نسيتوا | تنسىون | بتنسىون |
| هو | نسي | ينسى | بينسى |
| هي | نسيت | تنسى | بتنسى |
| هم | نسيوا | ينسىون | بينسىون |
