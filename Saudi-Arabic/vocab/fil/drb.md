# ضرب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ضرب |
| **Present** | يضرب |
| **Meaning** | hitting |
| **Root** | [ض-ر-ب](#roots/drb) |
| **Form** | I · ضرب / يضرب · base meaning: hitting |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">لا تضرب</span> | <span class="example-en" dir="ltr" lang="en">Don’t hit</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ضربت | أضرب | بضرب |
| إحنا | ضربنا | نضرب | بنضرب |
| أنت | ضربت | تضرب | بتضرب |
| أنتِ | ضربتي | تضربين | بتضربين |
| أنتم | ضربتوا | تضربون | بتضربون |
| هو | ضرب | يضرب | بيضرب |
| هي | ضربت | تضرب | بتضرب |
| هم | ضربوا | يضربون | بيضربون |
