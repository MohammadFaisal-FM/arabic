# كتب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | كتب |
| **Present** | يكتب |
| **Meaning** | writing |
| **Root** | [ك-ت-ب](#roots/ktb) |
| **Form** | I · كتب / يكتب |

---

## Example

| Arabic · English |
|------------------|
| أكتب رسالة — I’m writing a letter |

---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | كتبت | أكتب | بكتب |
| إحنا | كتبنا | نكتب | بنكتب |
| أنت | كتبت | تكتب | بتكتب |
| أنتِ | كتبتي | تكتبين | بتكتبين |
| أنتم | كتبتوا | تكتبون | بتكتبون |
| هو | كتب | يكتب | بيكتب |
| هي | كتبت | تكتب | بتكتب |
| هم | كتبوا | يكتبون | بيكتبون |
