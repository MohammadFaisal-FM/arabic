# حصل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | حصل |
| **Present** | يحصل |
| **Meaning** | happening / getting |
| **Root** | [ح-ص-ل](#roots/hsil) |
| **Form** | I · حصل / يحصل · base meaning: happening / getting |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">وش حصل؟</span> | <span class="example-en" dir="ltr" lang="en">What happened?</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | حصلت | أحصل | بحصل |
| إحنا | حصلنا | نحصل | بنحصل |
| أنت | حصلت | تحصل | بتحصل |
| أنتِ | حصلتي | تحصلين | بتحصلين |
| أنتم | حصلتوا | تحصلون | بتحصلون |
| هو | حصل | يحصل | بيحصل |
| هي | حصلت | تحصل | بتحصل |
| هم | حصلوا | يحصلون | بيحصلون |
