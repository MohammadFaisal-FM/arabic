# جرى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | جرى |
| **Present** | يجري |
| **Meaning** | running |
| **Root** | [ج-ر-ي](#roots/jry) |
| **Form** | I · جرى / يجري · base meaning: running |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">يجري بسرعة</span> | <span class="example-en" dir="ltr" lang="en">He runs fast</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | جرىت | أجري | بجري |
| إحنا | جرىنا | نجري | بنجري |
| أنت | جرىت | تجري | بتجري |
| أنتِ | جرىتي | تجريين | بتجريين |
| أنتم | جرىتوا | تجريون | بتجريون |
| هو | جرى | يجري | بيجري |
| هي | جرىت | تجري | بتجري |
| هم | جرىوا | يجريون | بيجريون |
