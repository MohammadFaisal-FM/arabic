# قدر

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | قدر |
| **Present** | يقدر |
| **Meaning** | being able |

## Example

| Arabic · English |
|------------------|

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | قدرت | أقدر | بقدر |
| إحنا | قدرنا | نقدر | بنقدر |
| أنت | قدرت | تقدر | بتقدر |
| أنتِ | قدرتي | تقدرين | بتقدرين |
| أنتم | قدرتوا | تقدرون | بتقدرون |
| هو | قدر | يقدر | بيقدر |
| هي | قدرت | تقدر | بتقدر |
| هم | قدروا | يقدرون | بيقدرون |
