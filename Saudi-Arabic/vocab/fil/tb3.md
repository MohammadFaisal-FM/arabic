# تبع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | تبع |
| **Present** | يتبع |
| **Meaning** | following |
| **Root** | [ت-ب-ع](#roots/tb3) |
| **Form** | I · تبع / يتبع · base meaning: following |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | تبعت | أتبع | بتبع |
| إحنا | تبعنا | نتبع | بنتبع |
| أنت | تبعت | تتبع | بتتبع |
| أنتِ | تبعتي | تتبعين | بتتبعين |
| أنتم | تبعتوا | تتبعون | بتتبعون |
| هو | تبع | يتبع | بيتبع |
| هي | تبعت | تتبع | بتتبع |
| هم | تبعوا | يتبعون | بيتبعون |
