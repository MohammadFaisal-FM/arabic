# د-ف-ع

| Field | Value |
|-------|-------|
| **Root** | د-ف-ع |
| **Letter** | د · دال |
| **Meaning** | paying / pushing |
| **Form I** | دفع / يدفع |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

---

## Example

| Arabic · English |
|------------------|
| دفعت الحساب — I paid the bill |
