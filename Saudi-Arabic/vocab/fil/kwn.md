# كان

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | كان |
| **Present** | يكون |
| **Meaning** | being |
| **Root** | [ك-و-ن](#roots/kwn) |
| **Form** | I · كان / يكون · base meaning: being |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">كان هنا</span> | <span class="example-en" dir="ltr" lang="en">He was here</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | كانت | أكون | بكون |
| إحنا | كاننا | نكون | بنكون |
| أنت | كانت | تكون | بتكون |
| أنتِ | كانتي | تكونين | بتكونين |
| أنتم | كانتوا | تكونون | بتكونون |
| هو | كان | يكون | بيكون |
| هي | كانت | تكون | بتكون |
| هم | كانوا | يكونون | بيكونون |
