# قرب

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | قرب |
| **Present** | يقرب |
| **Meaning** | approaching |
| **Root** | [ق-ر-ب](#roots/qrb) |
| **Form** | I · قرب / يقرب · base meaning: approaching |

| Arabic | English |
|--------|---------|

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | قربت | أقرب | بقرب |
| إحنا | قربنا | نقرب | بنقرب |
| أنت | قربت | تقرب | بتقرب |
| أنتِ | قربتي | تقربين | بتقربين |
| أنتم | قربتوا | تقربون | بتقربون |
| هو | قرب | يقرب | بيقرب |
| هي | قربت | تقرب | بتقرب |
| هم | قربوا | يقربون | بيقربون |
