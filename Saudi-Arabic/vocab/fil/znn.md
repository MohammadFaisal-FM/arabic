# ظنّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | ظنّ |
| **Present** | يظن |
| **Meaning** | thinking / assuming |
| **Root** | [ظ-ن-ن](#roots/znn) |
| **Form** | I · ظنّ / يظن · base meaning: thinking / assuming |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أظن كذا</span> | <span class="example-en" dir="ltr" lang="en">I think so</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | ظنّت | أظن | بظن |
| إحنا | ظنّنا | نظن | بنظن |
| أنت | ظنّت | تظن | بتظن |
| أنتِ | ظنّتي | تظنين | بتظنين |
| أنتم | ظنّتوا | تظنون | بتظنون |
| هو | ظنّ | يظن | بيظن |
| هي | ظنّت | تظن | بتظن |
| هم | ظنّوا | يظنون | بيظنون |
