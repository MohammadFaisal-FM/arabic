## Vocab & Sarf notes

| Word | Type (ism / fi'l / harf) | Root | Meaning |
|------|--------------------------|------|---------|
| وينه | **harf** / dialect | أ ي ن | where is she? (وين + ه) |
| قاطع | **fi'l** / **ism** | ق ط ع | cut off / cutting contact |
| مواصيل | **ism** | و ص ل | messages / contacts |
| غلا | **ism** | غ ل و | deep affection / love |
| حيلة | **ism** | ح و ل | way out / trick |
| مراسيل | **ism** | ر س ل | letters / messages |
| لبى | **fi'l** / idiom | ل ب ي | how precious / I sacrifice myself for |
| قدّ | **ism** | ق د د | figure / stature |
| طيف | **ism** | ط ي ف | ghost / vision / shadow |
| شوق | **ism** | ش و ق | longing |
| عنّب / توت / تين | **ism** | — | grapes / berries / figs (praise) |
| صمت | **ism** | ص م ت | silence |
| تأويل | **ism** | أ و ل | interpretation |

**Dialect note:** Khaliji / Saudi southern style — **وينه** = أين هي، **لبى** = تعظيم / فداء، **زين / شين** = beautiful / ugly.
