# سكن

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | سكن |
| **Present** | يسكن |
| **Meaning** | living / residing |
| **Root** | [س-ك-ن](#roots/skn) |

## Example

| Arabic · English |
|------------------|
| أسكن في الرياض — I live in Riyadh |

| إحنا | سكننا | نسكن | بنسكن |
| أنت | سكنت | تسكن | بتسكن |
| أنتِ | سكنتي | تسكنين | بتسكنين |
| أنتم | سكنتوا | تسكنون | بتسكنون |
| هو | سكن | يسكن | بيسكن |
| هي | سكنت | تسكن | بتسكن |
| هم | سكنوا | يسكنون | بيسكنون |
