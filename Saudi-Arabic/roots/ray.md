# ر-ا-ي

| Field | Value |
|-------|-------|
| **Root** | ر-ا-ي |
| **Letter** | ر · راء |
| **Meaning** | seeing |
| **Form I** | رأى / يرى |
| **Dialect** | Everyday Saudi / Najdi + MSA where common |

---

## Example

| Arabic · English |
|------------------|
| شفتك أمس — I saw you yesterday |
