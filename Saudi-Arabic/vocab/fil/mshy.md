# مشى

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | مشى |
| **Present** | يمشي |
| **Meaning** | walking |
| **Root** | [م-ش-ي](#roots/mshy) |
| **Form** | I · مشى / يمشي · base meaning: walking |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">أمشي كل يوم</span> | <span class="example-en" dir="ltr" lang="en">I walk every day</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | مشىت | أمشي | بمشي |
| إحنا | مشىنا | نمشي | بنمشي |
| أنت | مشىت | تمشي | بتمشي |
| أنتِ | مشىتي | تمشيين | بتمشيين |
| أنتم | مشىتوا | تمشيون | بتمشيون |
| هو | مشى | يمشي | بيمشي |
| هي | مشىت | تمشي | بتمشي |
| هم | مشىوا | يمشيون | بيمشيون |
