# عمل

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | عمل |
| **Present** | يعمل |
| **Meaning** | working / doing |
| **Root** | [ع-م-ل](#roots/3ml) |
| **Form** | I · عمل / يعمل · base meaning: working / doing |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">وش تشتغل؟</span> | <span class="example-en" dir="ltr" lang="en">What do you do?</span> |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | عملت | أعمل | بعمل |
| إحنا | عملنا | نعمل | بنعمل |
| أنت | عملت | تعمل | بتعمل |
| أنتِ | عملتي | تعملين | بتعملين |
| أنتم | عملتوا | تعملون | بتعملون |
| هو | عمل | يعمل | بيعمل |
| هي | عملت | تعمل | بتعمل |
| هم | عملوا | يعملون | بيعملون |
