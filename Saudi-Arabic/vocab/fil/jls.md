# جلس

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | جلس |
| **Present** | يجلس |
| **Meaning** | sitting |
| **Root** | [ج-ل-س](#roots/jls) |
| **Form** | I · جلس / يجلس · base meaning: sitting |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | جلست | أجلس | بجلس |
| إحنا | جلسنا | نجلس | بنجلس |
| أنت | جلست | تجلس | بتجلس |
| أنتِ | جلستي | تجلسين | بتجلسين |
| أنتم | جلستوا | تجلسون | بتجلسون |
| هو | جلس | يجلس | بيجلس |
| هي | جلست | تجلس | بتجلس |
| هم | جلسوا | يجلسون | بيجلسون |
