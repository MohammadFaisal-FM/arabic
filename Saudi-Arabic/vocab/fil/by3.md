# باع

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | باع |
| **Present** | يبيع |
| **Meaning** | selling |
| **Root** | [ب-ي-ع](#roots/by3) |
| **Form** | I · باع / يبيع · base meaning: selling |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | باعت | أبيع | ببيع |
| إحنا | باعنا | نبيع | بنبيع |
| أنت | باعت | تبيع | بتبيع |
| أنتِ | باعتي | تبيعين | بتبيعين |
| أنتم | باعتوا | تبيعون | بتبيعون |
| هو | باع | يبيع | بيبيع |
| هي | باعت | تبيع | بتبيع |
| هم | باعوا | يبيعون | بيبيعون |
