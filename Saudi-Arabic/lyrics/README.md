## How songs get added

1. You paste lyrics, a link, or a song name
2. Tutor saves a file under `Saudi-Arabic/lyrics/`
3. Index + PWA update
4. Push to GitHub → live on Pages

**Commands:** `add lyrics` · `lyrics` · `list songs`
