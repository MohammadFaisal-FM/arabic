# سقط

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | سقط |
| **Present** | يسقط |
| **Meaning** | falling |
| **Root** | [س-ق-ط](#roots/sqT) |
| **Form** | I · سقط / يسقط · base meaning: falling |

| Arabic | English |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | سقطت | أسقط | بسقط |
| إحنا | سقطنا | نسقط | بنسقط |
| أنت | سقطت | تسقط | بتسقط |
| أنتِ | سقطتي | تسقطين | بتسقطين |
| أنتم | سقطتوا | تسقطون | بتسقطون |
| هو | سقط | يسقط | بيسقط |
| هي | سقطت | تسقط | بتسقط |
| هم | سقطوا | يسقطون | بيسقطون |
