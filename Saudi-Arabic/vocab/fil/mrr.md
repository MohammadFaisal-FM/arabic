# مرّ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | مرّ |
| **Present** | يمر |
| **Meaning** | passing |
| **Root** | [م-ر-ر](#roots/mrr) |
| **Form** | I · مرّ / يمر · base meaning: passing |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | مرّت | أمر | بمر |
| إحنا | مرّنا | نمر | بنمر |
| أنت | مرّت | تمر | بتمر |
| أنتِ | مرّتي | تمرين | بتمرين |
| أنتم | مرّتوا | تمرون | بتمرون |
| هو | مرّ | يمر | بيمر |
| هي | مرّت | تمر | بتمر |
| هم | مرّوا | يمرون | بيمرون |
