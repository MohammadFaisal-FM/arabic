# قام

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | قام |
| **Present** | يقوم |
| **Meaning** | standing / getting up |
| **Root** | [ق-و-م](#roots/qwm) |
| **Form** | I · قام / يقوم · base meaning: standing / getting up |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | قامت | أقوم | بقوم |
| إحنا | قامنا | نقوم | بنقوم |
| أنت | قامت | تقوم | بتقوم |
| أنتِ | قامتي | تقومين | بتقومين |
| أنتم | قامتوا | تقومون | بتقومون |
| هو | قام | يقوم | بيقوم |
| هي | قامت | تقوم | بتقوم |
| هم | قاموا | يقومون | بيقومون |
