# مسك

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | مسك |
| **Present** | يمسك |
| **Meaning** | holding / catching |
| **Root** | [م-س-ك](#roots/msk) |
| **Form** | I · مسك / يمسك · base meaning: holding / catching |

---

## Example

| Arabic | English |
|--------|---------|
| <span class="example-ar" dir="rtl" lang="ar">امسك هذي</span> | <span class="example-en" dir="ltr" lang="en">Hold this</span> |


---

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | مسكت | أمسك | بمسك |
| إحنا | مسكنا | نمسك | بنمسك |
| أنت | مسكت | تمسك | بتمسك |
| أنتِ | مسكتي | تمسكين | بتمسكين |
| أنتم | مسكتوا | تمسكون | بتمسكون |
| هو | مسك | يمسك | بيمسك |
| هي | مسكت | تمسك | بتمسك |
| هم | مسكوا | يمسكون | بيمسكون |
