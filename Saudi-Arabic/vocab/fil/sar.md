# صار

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | صار |
| **Present** | يصير |
| **Meaning** | becoming |
| **Root** | [ص-ي-ر](#roots/sar) |
| **Form** | I · صار / يصير · base meaning: becoming |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | صارت | أصير | بصير |
| إحنا | صارنا | نصير | بنصير |
| أنت | صارت | تصير | بتصير |
| أنتِ | صارتي | تصيرين | بتصيرين |
| أنتم | صارتوا | تصيرون | بتصيرون |
| هو | صار | يصير | بيصير |
| هي | صارت | تصير | بتصير |
| هم | صاروا | يصيرون | بيصيرون |
