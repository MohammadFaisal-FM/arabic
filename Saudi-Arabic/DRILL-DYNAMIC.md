# Dynamic drill format (Cursor)

Use this whenever the learner says:

- `drill k t b` / `drill root ك-ت-ب` / `drill root كتب`
- `drill verb كتب` / `drill verb katab`

Generate **live** (do not require a pre-saved file). Prefer **everyday Saudi / Najdi** forms. Always include Arabic + transliteration + English.

---

## A) Root drill (`drill root` / `drill k t b`)

1. Normalize input to letters: `k t b` → **ك-ت-ب**
2. Identify Form I past stem (كتب) and meaning
3. Output sections below

### Output sections

1. **Root card** — root, core meaning, Form I past/present
2. **Root family** — past, present, masdar, اسم فاعل, اسم مفعول, 1–2 common nouns
3. **8 conjugations (most used)** — see table B
4. **For each of the 8:** one short example sentence (Najdi when natural)
5. **Details** — tense notes, weak-letter notes, common mistakes
6. Update `verb-root-tracker.md` if new; report **Coverage: X roots, Y verbs (Z drilled)**

---

## B) The 8 most-used conjugations (always this order)

| # | Pronoun | English | Slot to fill |
|---|---------|---------|--------------|
| 1 | أنا | I | past + present |
| 2 | إحنا | we | past + present |
| 3 | أنت | you (m.) | past + present |
| 4 | أنتِ | you (f.) | past + present |
| 5 | أنتم | you (pl.) | past + present |
| 6 | هو | he | past + present |
| 7 | هي | she | past + present |
| 8 | هم | they | past + present |

For each row show:

```text
[Pronoun] — Past: … · Present: …
Sentence: [Arabic]
Translit: …
English: …
```

Also add **Future (Najdi بـ)** for أنا and هو only (high frequency).

---

## C) Verb drill (`drill verb`)

Same 8 conjugations + imperative (أنت / أنتِ) + mark **Drilled = yes** in tracker.

---

## D) Example shape for ك-ت-ب

**Root:** ك-ت-ب · writing  
**Form I:** كتب / يكتب · to write

| Pronoun | Past | Present |
|---------|------|---------|
| أنا | كتبت | أكتب |
| إحنا | كتبنا | نكتب |
| أنت | كتبت | تكتب |
| أنتِ | كتبتي | تكتبين |
| أنتم | كتبتوا | تكتبون |
| هو | كتب | يكتب |
| هي | كتبت | تكتب |
| هم | كتبوا | يكتبون |

Future (Najdi): بكتب (I will write) · بيكتب (he will write)

Example lines (one per pronoun is enough):

- أنا: كتبت رسالة — *I wrote a letter.*
- هو: يكتب واجبه الحين — *He’s writing his homework now.*

---

## E) Sound vs weak roots

If the root is weak (و / ي / hamza) or hollow/defective, say so in **Details** and still fill the 8 slots with natural spoken forms.
