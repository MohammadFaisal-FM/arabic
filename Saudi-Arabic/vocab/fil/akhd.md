# أخذ

| Field | Value |
|-------|-------|
| **Type** | فعل · fiʿl (verb) |
| **Arabic** | أخذ |
| **Present** | ياخذ |
| **Meaning** | taking / getting |
| **Root** | [أ-خ-ذ](#roots/akhd) |
| **Form** | I · أخذ / ياخذ · base meaning: taking / getting |

## Conjugation

Everyday Saudi / Najdi. Future uses **بـ**.

| Pronoun | Past | Present | Future |
|---------|------|---------|--------|
| أنا | أخذت | أاخذ | باخذ |
| إحنا | أخذنا | ناخذ | بناخذ |
| أنت | أخذت | تاخذ | بتاخذ |
| أنتِ | أخذتي | تاخذين | بتاخذين |
| أنتم | أخذتوا | تاخذون | بتاخذون |
| هو | أخذ | ياخذ | بياخذ |
| هي | أخذت | تاخذ | بتاخذ |
| هم | أخذوا | ياخذون | بياخذون |
